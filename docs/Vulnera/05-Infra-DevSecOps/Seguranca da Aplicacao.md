# Seguranca da Aplicacao

## Objetivo
Garantir que a própria plataforma seja segura e coerente com seu propósito.

## Camadas principais
- HTTPS
- CORS
- Helmet
- rate limiting
- validação de DTOs
- JWT e refresh token seguro
- bcrypt
- ownership
- queries parametrizadas
- sanitização
- upload validado
- logs sem dados sensíveis
- auditoria
