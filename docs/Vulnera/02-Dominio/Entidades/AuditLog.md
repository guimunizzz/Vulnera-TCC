# AuditLog

## Definição
Registro estruturado de ações sensíveis executadas por usuários no sistema.

## Papel no sistema
Garantir rastreabilidade, accountability e capacidade de auditoria.

## Eventos importantes
- criação de vulnerability
- mudança de severidade
- mudanças administrativas de status

## Regras associadas
- [[RN20 - Criacao de Vulnerability gera auditoria]]
- [[RN21 - Mudanca de severidade gera auditoria]]
- [[RN15 - Admin pode sempre mover status com auditoria]]
