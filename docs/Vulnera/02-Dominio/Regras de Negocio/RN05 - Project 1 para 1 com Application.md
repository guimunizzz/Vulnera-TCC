# RN05 - Project 1 para 1 com Application

## Enunciado
Um Project é 1 para 1 com uma Application.

## Motivação
Simplificar o modelo operacional, o escopo e a rastreabilidade da análise.

## Impacta
[[Application]]
[[Project]]

## Consequências
- um projeto está vinculado a uma única aplicação
- a aplicação é a referência de escopo técnico do projeto
