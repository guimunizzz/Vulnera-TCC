# RN18 - Relatorios exigem Project em IN_REVIEW ou superior

## Enunciado
Relatórios só podem ser gerados quando o Project estiver em status igual ou superior a `IN_REVIEW`.

## Impacta
[[Project]]
[[Report]]
[[Relatorios]]

## Motivação
Evitar emissão prematura de documentação antes de a análise estar minimamente consolidada.
