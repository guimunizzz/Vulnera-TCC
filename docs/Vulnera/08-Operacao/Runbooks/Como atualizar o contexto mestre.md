# Como atualizar o contexto mestre

## Quando usar
Quando uma mudança impactar o entendimento global do projeto.

## Passos
1. atualizar a nota canônica afetada
2. registrar a mudança em [[Changelog do Projeto]]
3. criar ou atualizar ADR se a mudança for estrutural
4. atualizar MOC correspondente
5. verificar se [[Claude - Guia Operacional]] precisa de ajuste

## Regra
Nenhuma mudança estrutural deve existir apenas em nota solta.
