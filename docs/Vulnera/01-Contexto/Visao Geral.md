# Visao Geral

## Definição
Vulnera é uma plataforma web e mobile para gestão, acompanhamento e entrega de análises de segurança em aplicações.

## Estrutura macro
O projeto possui três aplicações integradas:
- web administrativa
- web cliente
- mobile cliente

## Papel do sistema
O Vulnera simula a operação de uma consultoria de segurança da informação, cobrindo:
- assinatura de plano
- definição de escopo
- execução da análise
- registro de findings
- acompanhamento do cliente
- emissão de relatórios
- revalidação

## Natureza do produto
O Vulnera não executa ataques reais.
É uma plataforma de gestão do serviço de consultoria.

## Eixos do projeto
- engenharia de software
- segurança da informação
- DevSecOps
- gestão de fluxo de trabalho
