# Objetivos

## Objetivo geral
Desenvolver uma plataforma full-stack em TypeScript para gestão, acompanhamento e entrega de análises de segurança, com back-end Express, front-end React + Vite, app mobile Expo, Docker e CI/CD.

## Objetivos específicos
- permitir contratação digital de planos
- centralizar empresas, usuários e aplicações
- registrar findings com classificação CVSS
- implementar máquina de estados
- permitir avaliação de maturidade
- gerar relatórios técnico e executivo
- oferecer mobile para acompanhamento do cliente
- implementar comentários e chat
- integrar Gemini de forma assistida
- manter trilha de auditoria
- demonstrar práticas DevSecOps
