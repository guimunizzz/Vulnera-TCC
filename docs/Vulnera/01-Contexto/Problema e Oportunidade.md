# Problema e Oportunidade

## Problema
Consultorias de segurança frequentemente sofrem com:
- escopo mal registrado
- evidências dispersas
- comunicação sem histórico
- baixa clareza para o cliente
- pouca rastreabilidade e auditoria

## Oportunidade
Criar uma plataforma que centralize:
- cadastro
- escopo
- análise
- findings
- relatórios
- maturidade
- comunicação
- auditoria

## Oportunidade pedagógica
O projeto também funciona como laboratório didático, usando aplicações de colegas como casos de análise com apoio de SonarQube e OWASP ZAP.
