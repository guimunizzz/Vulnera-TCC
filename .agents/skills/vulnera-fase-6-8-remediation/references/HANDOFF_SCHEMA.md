# Handoff entre agentes

Use este formato compacto em toda delegação.

```text
CHECKPOINT: CPx
TASK: <confirm|write-red-test|implement|review|validate|document>
FINDINGS: <IDs>
GOAL: <resultado objetivo>
SOURCE_FINDINGS: <arquivo/caminho do consolidado>
READ_SET_HINT: <arquivos/símbolos iniciais>
WRITE_SET_ALLOWED: <áreas permitidas ou NONE>
DO_NOT_TOUCH: <áreas proibidas>
VALIDATION_REQUIRED: <tipos>
CLOSURE_CRITERIA: <texto original/resumo fiel>
PREVIOUS_EVIDENCE: <RED/GREEN/review disponível>
OUTPUT: <schema abaixo>
```

## Saída de agente de escrita

```text
STATUS: DONE|BLOCKED|DIVERGENT
FINDINGS: ...
READ_SET: ...
WRITE_SET_ACTUAL: ...
CHANGE_SUMMARY: ...
TESTS_REQUESTED/EXECUTED: ...
RISKS: ...
NEEDS_REVIEW: YES
```

## Saída do Test Engineer

```text
STATUS: RED_PROVEN|GREEN_PROVEN|BLOCKED
FINDINGS: ...
TEST_FILES: ...
COMMANDS: ...
EXPECTED: ...
OBSERVED: ...
REPRODUCIBLE: YES|NO
```

## Saída do Patch Reviewer

```text
VERDICT: APPROVED|CHANGES_REQUIRED|UNRESOLVED
FINDINGS: ...
PATCH_MATCHES_ROOT_CAUSE: YES|NO
BYPASS_REMAINING: ...
REGRESSION_RISK: ...
UNRELATED_CHANGES: ...
REQUIRED_CHANGES: ...
```

## Saída do Closure Validator

```text
FINDING: <ID>
VERDICT: CLOSED|REFUTED|BLOCKED|PARTIALLY_VALIDATED
STATIC_EVIDENCE: ...
RED_PROOF: ...
GREEN_PROOF: ...
VALIDATION_REQUIRED: ...
VALIDATION_EXECUTED: ...
CLOSURE_CRITERIA_MET: YES|NO
EVIDENCE: ...
```
